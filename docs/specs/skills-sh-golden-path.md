# Spec: skills.sh Golden Path pack

## Goal
Curate a short MIT-friendly skills.sh set for Golden Path workflows.

## Trigger / users
Template maintainers and children wanting TDD/shape/handoff skills.

## Requirements
- docs/SKILLS_RECIPES.md lists curated skills (tdd, grill-me, implement-spec, handoff, verification-before-completion, find-skills).
- Optional thin .cursor/skills wrappers or install notes; human confirm; cap set.
- No Feishu/Lark/Twitter/Azure-only packs on FOSS path.

## Out of scope
Vendoring the entire skills.sh leaderboard.

## Acceptance checks
- SKILLS_RECIPES.md exists; at least one project skill folder present or install path documented.

## Assumptions (flagged)
- Skills are not a second AGENTS.md.

## Open questions
None.

## Files likely touched
docs/SKILLS_RECIPES.md, .cursor/skills/, tests/
