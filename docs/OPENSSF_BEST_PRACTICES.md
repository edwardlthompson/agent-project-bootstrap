# OpenSSF Best Practices badge

Public entry: [project 14564](https://www.bestpractices.dev/en/projects/14564) (formerly CII Best Practices).

Agents cannot log into bestpractices.dev. Proposed answers live in [`.bestpractices.json`](../.bestpractices.json). After that file is on `main`, a maintainer who is logged in clicks **Save (and continue) 🤖** on the project edit form so the site re-reads the repo.

Do not invent Met answers. Status `?` in the JSON is ignored. Leave personal-knowledge rows (`know_secure_design`, `know_common_errors`) and issue-response rates for a human.
