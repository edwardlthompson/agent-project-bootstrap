# Template identity (parent)

Visual identity for **agent-project-bootstrap** (this GitHub Template), not for child products.

Child / Golden Path assets stay under [`../assets/`](../assets/). Sync (`scripts/sync-design-tokens.py`) never reads this folder. Do not overwrite `branding/assets/*.svg` with parent art.

## Shipped

| Role | Choice |
|------|--------|
| **Logo** | 2D human ↔ robot handshake (`logo-mark.png`) — from manual crop of the photoreal shot |
| **Splash / README hero** | Full photoreal handshake (`readme-splash.jpg`) — person and humanoid agent |

**Metaphor:** Human + coding agent collaboration (handshake), not path-merging.  
**Palette:** ink `#0F1419` · signal amber `#E8A317` · mist `#E8EEF2` · navy sleeve  
**Wordmark:** `agent-project-bootstrap` (full) / `APB` (compact)  
**Tagline:** Ship a FOSS app with an agent that already knows the rules.
